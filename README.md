# 📊 Global Sales Analysis (2010–2017)

Sales data analysis across 12 product categories, 47 countries and 8 years, covering both online and offline channels using Google Sheets.

---

## ✅ Key Metrics

| KPI | Value |
|---|---|
| Total Orders | 1,331 |
| Total Revenue | $1,702M USD |
| Total Profit | $501M USD |
| Profit Margin | ~29.5% |
| Countries Covered | 47 |
| Period | 2010–2017 |

---

## 🔍 Main Insights

- **Cosmetics** has the highest profit ($92.7M) despite not leading in revenue — superior margins.
- **Office Supplies** leads in revenue ($402.2M).
- **Europe** accounts for 88.5% of total revenue; Asia contributes only 5.5%.
- Online vs Offline split is nearly equal: **51.2% Offline / 48.8% Online**.
